# 01 – Olympics Analysis

## Overview

The first phase of the project focused on preparing and analysing Tokyo 2020 Olympics data to investigate the relationship between athlete participation and medal success.

Using Python, Pandas, and statistical methods, I prepared the datasets, performed exploratory data analysis (EDA), and developed two linear regression models.

## Data Analysis Activities

### 1. Final Olympics Analysis Notebook

I developed a Jupyter Notebook containing the complete data analysis, from data preparation to statistical modelling and evaluation.

I combined athlete participation and medal datasets, checked data quality, and created a dataset containing 93 medal-winning countries.

I then explored distributions, correlations, and outliers before developing two Ordinary Least Squares (OLS) regression models to investigate the relationships between athlete count, discipline count, and total medals.

### 2. Model Evaluation

I evaluated both regression models using correlation coefficients, R² values, statistical significance, and residual analysis.

I also investigated regression assumptions, including residual normality and homoscedasticity, to understand the reliability and limitations of the models.

This helped me understand the importance of interpreting statistical results critically rather than relying only on model performance metrics.

## Outcome

The analysis showed positive relationships between both athlete count and discipline count and total medals, with athlete count demonstrating the stronger association.

This phase strengthened my skills in **Python, data preparation, exploratory data analysis, linear regression, and statistical evaluation**.
